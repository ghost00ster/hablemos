# Hablemos · Terapeuta interactivo de lenguaje

Tablero de comunicación aumentativa (CAA) con pictogramas ARASAAC y voz en español,
configurable por edad, nivel de lenguaje y condición (TEA, TDL, apraxia, síndrome de Down, TDAH, etc.).

Sitio estático: no necesita compilación. Se publica tal cual en Vercel.

Pictogramas: Sergio Palao. Origen: ARASAAC (https://arasaac.org). Licencia CC BY-NC-SA. Propiedad: Gobierno de Aragón.
